# cv-datafie-
CV datafié interactif inspiré de Dear Data et de la sémiologie graphique de Jacques Bertin. Projet académique (Master NET - Université Paris 8)
# CV Datafié de Tamazight Aoudia : Ce que j'ai fait 🎨📊

Ce projet a été réalisé par **Tamazight Aoudia** dans le cadre d'un cours de sémiotique. Il s'agit d'un **CV datafié** inspiré du projet de *slow data* **Dear Data** (de Giorgia Lupi et Stefanie Posavec) et fondé sur la sémiologie graphique de **Jacques Bertin**.

## 🎯 Objectif du projet
Traduire un parcours académique et professionnel (8 expériences et projets en France et en Algérie) en un **portrait de données visuel** sous forme de constellation manuscrite, accompagné d'un dictionnaire sémiotique rigoureux.

## 🛜 Le Système Sémiotique (Variables visuelles)
Chaque forme géométrique représente une variable précise :
- **La Forme (Morphologie) :** 
  * Cercle = Job Professionnel
  * Carré = Académique & Projet
  * Triangle = Bénévolat & Engagement associatif
- **La Taille (Dimension) :** Représente la durée et l'ampleur de l'expérience dans le temps.
- **Le Remplissage (Valeur / Saturation) :** Code l'intensité de l'engagement (Tons foncés = haute intensité / public ; Tons clairs = apprentissage / léger).
- **La Bordure (Texture de contour) :** 
  * Trait continu = Travail en équipe / public
  * Pointillés = Autonomie totale

## 💻 Technologies utilisées
- HTML5 / CSS3 (Flexbox, variables visuelles personnalisées)
- Google Fonts (Police manuscrite *Caveat*)
- Design responsive en constellation organique façon carnet de notes.
